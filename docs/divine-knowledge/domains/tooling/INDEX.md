# Tooling Leads and Development Enhancements

Status: **LIGHTWEIGHT OPTIONAL LANE**

## Current doctrine

- Prefer the connected GitHub tools for repository inspection, documentation,
  issue/PR administration, and routine repository-object work.
- Use Codex when substantial implementation, executable testing, or deeper code
  reasoning materially requires a full workspace.
- Use GitHub Copilot for bounded implementation or independent review when it
  offers a concrete advantage.
- Availability alone is not a reason to use or install a tool.
- No tool supersedes `AGENTS.md`, accounting invariants, owner merge authority,
  isolated branches, or TornPDA manual gates.

## Discovery model

Notice promising ChatGPT, Codex, plugin, MCP, GitHub, testing, review, research,
or automation tooling primarily through word of mouth and organic discovery. A
bounded survey may be proposed at a comfortable project checkpoint. Valid
outcomes include trial, adopt, reserve, redundant, and reject; adopting nothing
is acceptable.
