# Tooling Leads / Development Enhancements

Status: **LIGHTWEIGHT DISCOVERY LANE**

Checkpoint: 2026-08-30

## Goal

Keep an eye out for ChatGPT, Codex, plugin, MCP, GitHub, testing, review, research, automation, or other developer tooling that could materially improve TornScriptures work.

This is intentionally not a mandatory plugin-acquisition program. TornScriptures does not need to adopt an add-on merely because one exists. The purpose is to notice potentially useful tools we may otherwise miss, especially through developer/community word of mouth, GitHub discussions, Reddit/forums, direct recommendations, or promising tools encountered organically.

## Operating rule

When the project reaches a natural point where a bounded tooling survey would be useful, the assistant may propose a short Tool Discovery session. The survey should ask whether any missing capability could reduce paid-agent usage, duplicated work, risk, or manual effort. If nothing is compelling, adopt nothing and return to product work.

Candidate outcomes: `trial`, `adopt`, `reserve`, `redundant`, `reject`.
