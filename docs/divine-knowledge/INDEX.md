# Subtree of Divine Knowledge

Persistent TornScriptures project memory maintained by the project assistant under owner-approved standing authority.

## Boot sequence

For substantive TornScriptures work:

1. Read `NOW.md`.
2. Read the relevant domain `INDEX.md`.
3. Read the active chapter `INDEX.md` when one exists.
4. Follow provenance into canonical repository docs, issues, PRs, commits, or evidence only as needed.
5. Recheck mutable repository facts before consequential action.

Do not reload the entire subtree by default.

## Authority

See `AUTHORITY.md`. The project assistant may maintain, reorganize, consolidate, supersede, archive, rename, or delete content inside `docs/divine-knowledge/**` when useful for project continuity. Product code, releases, branch deletion, spending, gameplay behavior, credentials, and merges remain outside that standing authority.

## Provenance rule

This subtree is a navigation and continuity layer, not a replacement for canonical evidence. Important claims should point to their source. If this tree conflicts with current repository evidence, current repository evidence wins and the tree should be corrected.

## Staleness rule

Mutable facts such as `main` SHA, issue state, branch containment, provider prices, API versions, and current market state must be rechecked before consequential use. Snapshot entries record what was known at a time, not eternal truth.
